## Current batch

## Batch folders

The main working files for this batch are under [`docs/mapp_project_00050/mapp_batch_00283/`](docs/mapp_project_00050/mapp_batch_00283/).

- [`metadata/`](docs/mapp_project_00050/mapp_batch_00283/metadata/): raw and curated sample metadata.
- [`metadata/original/`](docs/mapp_project_00050/mapp_batch_00283/metadata/original/): original metadata files as received.
- [`metadata/treated/`](docs/mapp_project_00050/mapp_batch_00283/metadata/treated/): cleaned or transformed metadata files.
- [`results/`](docs/mapp_project_00050/mapp_batch_00283/results/): analysis outputs generated for the batch.
- [`results/cytoscape/`](docs/mapp_project_00050/mapp_batch_00283/results/cytoscape/): network files and exports for Cytoscape.
- [`results/met_annot_enhancer/`](docs/mapp_project_00050/mapp_batch_00283/results/met_annot_enhancer/): metabolite annotation enhancement outputs.
- [`results/metaboanalyst/`](docs/mapp_project_00050/mapp_batch_00283/results/metaboanalyst/): MetaboAnalyst-ready files and outputs.
- [`results/mzmine/`](docs/mapp_project_00050/mapp_batch_00283/results/mzmine/): MZmine batch files and processing outputs.
- [`results/sirius/`](docs/mapp_project_00050/mapp_batch_00283/results/sirius/): SIRIUS/CSI:FingerID outputs.
- [`results/stats/`](docs/mapp_project_00050/mapp_batch_00283/results/stats/): statistical analysis outputs.
- [`results/xcalibur/`](docs/mapp_project_00050/mapp_batch_00283/results/xcalibur/): Xcalibur exports and related files.
- [`report/`](docs/mapp_project_00050/mapp_batch_00283/report/): rendered or intermediate report files.
